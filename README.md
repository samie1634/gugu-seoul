# 구구 서울 · Gugu Seoul

비둘기가 되어 광화문광장에서 걷고, 종로의 지붕 위를 날아다니는 작은 3D 웹 놀이터입니다. 스페이스를 톡 누르면 날갯짓하고, 꾹 누르면 날개를 펴고 활공합니다.

광화문과 궁궐 담장, 광장과 세종대왕·이순신 동상, 세종문화회관, 세종대로, 종로와 보신각, 청계천을 직접 만든 도형으로 구성했습니다. 사진 실측 지도 대신 장소의 배치와 특징을 살린 스타일화된 맵입니다.

**현재 공개 버전은 초기 플레이 가능한 기본판입니다.** 사실적인 물·건물·지형, 상호작용 물건, 7종 새, 인간과 다른 동물 NPC, 기존 음원 연결은 별도로 개선 중입니다. 지금 버전은 직접 만든 간단한 도형 맵과 합성음으로 비행·걷기·외형 선택을 체험하는 단계입니다.

## 실행

Node.js **24 이상**, pnpm **11.25.0**을 사용합니다.

```sh
git clone https://github.com/samie1634/gugu-seoul.git
cd gugu-seoul
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시되는 `http://127.0.0.1:5173/`을 엽니다. `index.html`을 파일로 직접 열지 말고 로컬 서버를 사용해 주세요. 패키지 설치가 끝나면 게임 실행에 외부 지도·영상·오디오 서버나 API 키가 필요하지 않습니다.

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm preview
```

빌드 산출물은 `dist/`입니다. `pnpm preview`는 로컬 미리보기이며 외부 서비스에 배포하지 않습니다. 이 저장소는 GitHub Pages나 다른 호스팅에 자동 배포하는 설정을 포함하지 않습니다.

pnpm 명령이 PATH에 없는 환경에서, 의존성이 이미 설치돼 있다면 다음 명령도 같은 개발 서버를 엽니다.

```sh
node node_modules/vite/bin/vite.js --host 127.0.0.1
```

## 조작

| 조작 | 키보드 | 터치 |
| --- | --- | --- |
| 걷기 / 비행 속도 조절 | W / S 또는 위 / 아래 화살표 | 왼쪽 패드 앞뒤 |
| 방향 전환 | A / D 또는 좌 / 우 화살표 | 왼쪽 패드 좌우 |
| 날갯짓 상승 | 스페이스를 짧게, 여러 번 | 펄럭을 짧게, 여러 번 |
| 활공 | 스페이스를 계속 누르기 | 펄럭을 계속 누르기 |
| 하강 / 착륙 | Shift 또는 날개 놓기 | 내려가기 또는 펄럭 놓기 |
| 구구 울기 | C | 구구 |
| 비둘기 눈높이 / 뒤에서 보기 | V 또는 카메라 버튼 | 카메라 버튼 |
| 일시정지 / 조작 안내 | Esc 또는 ? | ? |
| 외형 선택 | 모습 | 모습 |

지상에서 이동하면 머리를 까딱이고 발을 번갈아 움직이며 주기적으로 구구 웁니다. 활공은 천천히 고도를 잃으며 앞으로 이동합니다. 계속 누르는 것만으로 무한 상승하지 않고, 더 높이 가려면 다시 톡톡 날갯짓해야 합니다. 지면과 건물 지붕에 내려앉을 수 있습니다. 두 손가락으로 방향 패드와 날갯짓을 함께 조작할 수 있습니다.

## 머문 만큼 열리는 모습

| 누적 플레이 시간 | 선택할 모습 |
| --- | --- |
| 처음부터 | 도시 비둘기 |
| 3분 | 흰 비둘기 |
| 8분 | 수리부엉이 |

모습은 **실제 누적 플레이 시간**으로 열립니다. 생김새가 바뀌고 수리부엉이는 울음 표현도 바뀝니다. 비행 능력은 같습니다.

시작 화면, 일시정지/모습 선택 창, 숨겨진 탭의 시간은 더하지 않습니다. 활성 게임 탭에서 가만히 쉬는 시간은 포함합니다. 브라우저가 멈춘 긴 프레임을 한 번에 더하지 않습니다. 시간·선택한 모습·음소거 여부를 이 브라우저의 `localStorage`에 저장하며, 새로고침하면 광장에 다시 나타납니다. 사이트 데이터 삭제나 다른 브라우저/주소를 사용하면 기록이 이어지지 않습니다. 저장이 막혀 있어도 게임은 실행됩니다.

조작 안내의 **광장으로 돌아가기**는 위치만 바꿉니다. **플레이 기록 초기화**는 한 번 더 확인한 뒤 시간과 모습을 초기화합니다.

## 범위와 기술

- Three.js + TypeScript + Vite. 원본 모델·지형·SVG와 Web Audio 합성음을 사용합니다.
- 광화문을 북쪽, 세종대로를 남북, 종로를 동쪽, 청계천을 남쪽에 둔 압축된 약 1.2km 규모의 놀이터입니다. 건물 크기·거리·고도는 게임에 맞게 조정했습니다.
- 현재는 **혼자 탐험하는 버전**입니다. 다른 비둘기와 차량은 NPC이며, 실시간 다중 접속·대화·실측 디지털 트윈은 구현하지 않았습니다.
- 현재 선택 가능한 모습은 회색 비둘기·흰 비둘기·수리부엉이입니다. 비둘기·참새·까마귀·까치·올빼미·부엉이·황조롱이의 7종 설계와 사실적인 맵, 인간·개·고양이·쥐 등의 NPC는 별도 개선 중입니다.
- 현재 음향은 Web Audio 합성음입니다. 기존 제공 녹음 파일은 포함하지 않았으며, 재배포 권리 확인을 거친 음원 연결은 후속 범위입니다.
- WebGL 2 지원 브라우저가 필요합니다. 모바일 조작과 반응형 레이아웃을 제공하지만 실제 휴대전화 기기의 성능·스피커 청취는 별도 확인이 필요합니다.
- 계정·백엔드·외부 API·분석 추적·유료 서비스가 없습니다.

구현은 `src/world.ts`(맵), `simulation.ts`(비행/충돌), `bird.ts`(모델/애니메이션), `input.ts`(입력), `progress.ts`(해제/저장), `audio.ts`(합성음), `main.ts`(화면/게임 루프)로 나뉩니다.

## 검증

`pnpm test`는 비행, 지상/벽/옥상/문 아래 충돌, 프레임 간 안정성, 키 반복, 포커스 상실, 동시 터치와 취소, 해제 경계, 일시정지 시간 제외, 저장 복구와 초기화, 오디오 스케줄링을 검사합니다. 기본판의 자동 테스트 20개, TypeScript 검사, lint와 빌드를 통과했습니다.

데스크톱과 모바일 크기의 브라우저에서 걷기, 자동 구구, 짧은 날갯짓·홀드 활공·착륙, 시점 전환, 3분/8분 외형 해제와 선택, 새로고침 저장과 초기화 흐름을 확인했습니다. 실제 휴대전화 성능과 스피커 청취, 일반 브라우저의 배경 탭 중단은 추가 검수가 필요합니다. 현재 JS 번들은 약 598.64 kB / gzip 155.67 kB로 Vite의 500 kB 청크 권고 경고가 남아 있습니다.

```sh
pnpm audit:public
```

이 읽기 전용 스크립트는 현재 Git에 포함한 파일의 경로·비밀 형태·개인 경로 혼입을 검사합니다. 자동 검사가 모든 비밀을 찾아내는 것은 아니므로 파일 목록과 변경 내용도 함께 검토해야 합니다.
