# 구구 서울 · Gugu Seoul

서울 종로와 광화문을 게임용으로 압축한 3D 산책 프로토타입입니다. 비둘기가 되어 광장을 걷고 지붕 위를 날 수 있습니다. 직접 작성한 절차적 맵·새·인간·개·고양이·쥐 모델과 Web Audio 합성음을 사용합니다.

## 로컬 실행

Node.js 24 이상과 pnpm 11.25.0이 필요합니다. 이 소스를 받은 프로젝트 폴더에서 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. `index.html`을 파일로 직접 열어 실행하는 방식은 지원하지 않습니다. 의존성 설치 후에는 지도·영상·녹음 서버나 API 키가 필요하지 않습니다.

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm preview
```

`build`는 `dist/`를 만들고 `preview`는 그 결과의 로컬 미리보기를 엽니다. 기존 GitHub Pages 워크플로는 main에 검증된 변경 묶음을 반영할 때 빌드·검사 후 배포합니다. 자동 시험은 공개된 시험 파일을 실행하며, 최종 브라우저·실기기 인수와 구분합니다.

## 조작과 모습

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동·방향 | W/S, A/D 또는 방향키 | 왼쪽 패드 |
| 날갯짓·활공 | 스페이스를 톡·길게 | 펄럭 버튼을 톡·길게 |
| 하강 | Shift | 내려가기 |
| 울기 | C | 구구 |
| 눈높이·뒤 시점 전환 | V | 시점 버튼 |
| 일시정지·조작 안내 | Esc 또는 ? | ? |

회색 비둘기는 처음부터 선택할 수 있습니다. 활성 플레이 시간 180초에 흰 비둘기, 480초에 수리부엉이가 열립니다. 선택·플레이 시간·음소거는 브라우저의 localStorage에 저장합니다. 일시정지와 비활성 시간은 진행도에서 제외합니다.

## 현재 검증 범위

현재 소스에는 실제 지지면을 사용하는 이동·카메라 복귀, 인간·개·고양이·쥐 v1 런타임, 종별 몸체·눈·카메라·착륙과 원자적 외형 교체 코어가 연결돼 있습니다. 내부 코어는 비둘기·참새·까마귀·까치·올빼미·수리부엉이·황조롱이를 구분합니다. 사용자 선택은 기존 회색/흰 비둘기와 수리부엉이 세 모습이며, 다른 다섯 종의 메뉴·해금·저장 정책은 아직 노출하지 않습니다. v1 NPC 보행의 발 미끄러짐과 표시 계단은 남아 있습니다. 모바일 가로 터치의 최종 검수, 실제 휴대전화 성능·동시 두 손가락·실제 숨긴 탭·연속 카메라 체감·실제 음향 재생은 확인하지 못했습니다. 지도는 직접 저작한 압축 지형이며 실제 서울의 정확한 좌표·거리·입면을 재현한 정밀 지도는 아닙니다. 새 시각안·물 재질 후속·환경음 엔진·원음 파일·쪼기/먹이/숨은 변신은 이 묶음에 포함하지 않았습니다. 전체 앱·현실감의 최종 인수는 보류 상태입니다.

## 소스 공개 전 파일 검사

Git clone으로 받은 저장소의 최상위 폴더 이름이 `gugu-seoul`이고 검사할 파일을 Git에 포함한 상태에서 실행합니다.

```sh
pnpm audit:public
```

현재 감사 도구는 Git metadata를 사용합니다. `.git`이 없는 소스 ZIP에서는 이 명령을 실행할 수 없습니다. 패턴 검사는 파일 목록·자산 권리·수동 내용 검토와 함께 사용합니다.
